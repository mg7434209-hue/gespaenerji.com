# Ground-Mounted Solar: Assessment & Install

Ground-mounted PV uses support structures installed on land. Land assessment, engineering and installation planning are tailored to each project.

## What is checked when selecting land?

Slope, shading, soil, access, drainage and distance to the connection point are assessed. Ownership, land use and authority requirements are checked for each project.

## How is capacity determined?

Row spacing, maintenance access, shading and connection capacity are considered alongside area. Consumption and generation simulation inform the design.

## Preparing for assessment

Share location, usable area, existing connection and consumption. For irrigation, include pump power, daily operating hours and season.
